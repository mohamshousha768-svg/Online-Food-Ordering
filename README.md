# Online Food Ordering

## Overview

Online Food Ordering is a database design project for an online food ordering system.

The current version focuses on designing and documenting the database structure. The project is planned to be developed further into a complete application using Java, Object-Oriented Programming (OOP), and a graphical user interface.

## Current Version

The current documentation includes:

* Entity Relationship Diagram (ERD)
* Database Schema
* Database Normalization
* SQL Code
* Detailed explanations
* Project documentation
* Sources and references

## Future Development

The project is planned to be expanded in the future to include:

* Java OOP implementation
* Graphical User Interface (GUI)
* Database integration
* Full online food ordering functionality

## Documentation

The complete database design, including the ERD, schema, normalization, SQL code, explanations, and sources, is available in the Word documentation file included in this repository.

## Technologies

Current:

* Database Design
* SQL

Planned:

* Java
* Object-Oriented Programming (OOP)
* GUI
* Database Integration

## Purpose

This project was created as a practical database design project and will be continuously developed to become a complete online food ordering application.
